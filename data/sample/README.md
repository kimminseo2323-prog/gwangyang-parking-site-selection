# 샘플 데이터 안내

`grid_features_sample.csv` — 150행, numpy seed 42 난수로 생성한 **합성 데이터**. 실제 광양시 격자 값과 무관하다.

| 컬럼 | 대응 코드 입력 | 설명 |
|---|---|---|
| `gid`, `행정동명`, `공영주차장_여부` | `요인분석.py` `factor_result*`, `P_median_func.py` `gid` | 격자 ID, 읍면동(광양읍/중마동), 타깃(1=공영주차장 존재) |
| `x`, `y` | `P_median_func.py` `geo_df['geometry']` 대체 | 격자 중심 좌표(m, 임의 원점). `shapely.Point(x, y)`로 geometry 생성 |
| `거주인구`, `등록차량수`, `총주차면수`, `유동인구12시`, `유동인구20시` 및 `.../전체주차장주차면수` 4개 | `요인분석.py`가 `최종영향인자_*.csv`로 저장하는 컬럼 | P-median 가중치(`factor_nm`) 후보 |
| `공영주차장_주차면수_300M_여부`, `유동인구_2시/시간평균`, `유동인구_18시/시간평균`, `버스정류장_300M(_여부)`, `공원_300M(_여부)`, `최근접_주민센터직선거리`, `전체주요시설_300M`, `복합_총주차면수/거주인구` | `요인분석.py` `var_list` (로지스틱 입력 12개 변수) | 300m 반경 기준 영향인자 일부 |
| `Score` | `요인분석.py` 출력 | 로지스틱 예측확률 자리 (샘플은 난수) |

원본 코드는 60개 영향인자 전체(`factor_result2.pkl`)를 사용하지만 샘플에는 모델 입력에 쓰인 변수와 P-median 가중치 컬럼만 담았다.
